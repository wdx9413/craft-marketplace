# craft-codebase for DSH

Install this directory with dsh plugin --profile default add <directory>.
Use craft_codebase_tools to discover MCP schemas, then craft_codebase_call.
Follow skills/craft-codebase/SKILL.md; the complete Skill is bundled here.
The local runtime works without npx downloads or Hooks. CRAFT_DATA_DIR may be shared with other Hosts.
